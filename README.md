# PVA/Na-MMT interface: MD + surrogate-assisted (qEHVI) optimization

Data and code supporting the article:

M. Z. Koç, "Interfacial adhesion, hydrogen bonding and thermal behavior of
poly(vinyl alcohol)/sodium montmorillonite composites: A molecular dynamics
study with a surrogate-assisted optimization framework", Computational
Materials Science (2026), accepted for publication.

## Overview
All-atom MD of a PVA/Na-montmorillonite interface (CGenFF + INTERFACE force
field, LAMMPS), five interfacial descriptors, and MD-in-the-loop
multi-objective Bayesian optimization (qEHVI, BoTorch) over operating
temperature and clay loading.

## Contents

### Interface model (Sections 3.1–3.3, 4.1–4.3)
- `in.interface.txt` — LAMMPS input: reads `interface.data`, equilibrates the
  interface and writes `interface_equil.data`; measures interfacial properties
- `interface.data` — initial assembled PVA/Na-MMT configuration (input)
- `interface_equil.data` — equilibrated reference interface (50 PVA chains, 9074 atoms)
- `hbond.py` — PVA(–OH)···clay(O) hydrogen-bond counting (Section 4.3)
- `plot_density_EN.py` — interfacial mass-density profile (Fig. 2)

### Glass-transition temperature (`tg/`, Section 4.4)
- `tg_scan.inp` — stepwise NPT cooling of bulk PVA from 450 to 250 K (25 K steps)
- `start.data` — equilibrated bulk PVA configuration (input to `tg_scan.inp`)
- `tg_data.txt` — raw density–temperature data
- `tg_analiz_EN.py` — bilinear fit and Tg estimate (Fig. 3)

### Optimization over temperature (Sections 3.4, 4.5)
- `figure_qehvi_vs_random_EN.py` — qEHVI vs random search on a synthetic
  two-objective test problem, 10 seeds (Fig. 4)
- `bridge_level1_v2.py` — MD-in-the-loop qEHVI with operating temperature as
  design variable (adhesion vs PVA mobility)
- `bridge_final2.txt` — raw output of the run reported in Fig. 5
- `plot_bridge_EN.py` — Fig. 5

### Clay-loading series (Section 4.6)
- `run_L2_grid.sh` — generates the 50/37/25/13-chain systems by deleting PVA
  chains from `interface_equil.data` (clay fixed), equilibrates them and
  measures adhesion
- `interface_L2_{50,37,25,13}.data` — resulting configurations
- `L2_grid_results.txt` — adhesion results
- `plot_L2_clay_EN.py` — Fig. 6

### Optimization over clay loading (Sections 4.7, 4.9)
- `bridge_level2.py` — MD-in-the-loop qEHVI with clay loading (PVA chain
  number) as design variable (work of adhesion vs PVA MSD)
- `error_bars.py` — repeatability study (3 systems × 3 random seeds)
- `plot_L2_bridge_EN.py`, `plot_L2_bridge_errorbars_EN.py` — Fig. 7
- `qehvi_vs_random_realMD.py` — qEHVI vs random search on the real-MD-derived
  response surface, 20 seeds (Fig. 8)
- `ff_sensitivity.py` — PVA partial-charge sensitivity analysis (±10%, Section 4.9)

## Requirements
- LAMMPS (22 Jul 2025 or compatible), built with the MOLECULE and KSPACE packages
- Python 3.11 with: `botorch`, `torch`, `gpytorch`, `numpy`, `matplotlib`

## Notes on reproduction
- The optimization scripts call LAMMPS directly. They were run with
  `WORKDIR = ~/CLAY/interface` and `conda run -n md mpirun -np 10 lmp`;
  adjust `WORKDIR` and `LAMMPS_CMD` at the top of each script for your system.
- Run all scripts from the repository root, except those in `tg/`.
- Some code comments are in Turkish.
- Fig. 1 (OVITO rendering) and Fig. 9 (schematic) were not generated by code.
